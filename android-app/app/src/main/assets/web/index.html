GitHub public clone

Real Termux modeคำสั่ง Linux จริง เช่น `apt`, `pkg`, `sudo`, `bash` และ `git clone` แบบเต็ม ให้รันในแอป Termux โดยตรง ดาวน์โหลด source และคู่มือจาก GitHub repository ได้
Safetyหน้านี้ไม่รัน shell บนมือถือ และไม่ส่งไฟล์ขึ้น server อัตโนมัติ ไฟล์จะอยู่ใน session ของ Browser จนกว่าจะปิดหรือ refresh หน้า
